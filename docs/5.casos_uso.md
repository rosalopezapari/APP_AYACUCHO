# CASOS DE USO - QORY AYACUCHO

## Actor principal: Ciudadano (Turista / Visitante)

---

### CU-01: Registrar cuenta
| Campo | Detalle |
|-------|---------|
| **ID** | CU-01 |
| **Nombre** | Registrar cuenta de ciudadano |
| **Actor** | Visitante no registrado |
| **Descripción** | El visitante crea una cuenta proporcionando nombre, email, teléfono, país y contraseña |
| **Precondición** | El email no debe estar registrado previamente |
| **Flujo principal** | 1. Ingresa nombre, email, teléfono, país, contraseña<br>2. El sistema valida email, teléfono y que las contraseñas coincidan<br>3. El sistema guarda el registro y asigna un ID único<br>4. Muestra mensaje de éxito y redirige al login |
| **Flujo alternativo** | 2a. Email inválido → mensaje de error<br>2b. Teléfono inválido → mensaje de error<br>2c. Contraseñas no coinciden → mensaje de error<br>2d. Email duplicado → mensaje de error |
| **Postcondición** | Ciudadano registrado en la base de datos |

### CU-14: Planificador de viaje integrado
| Campo | Detalle |
|-------|---------|
| **ID** | CU-14 |
| **Nombre** | Planificador integrado de viaje |
| **Actor** | Ciudadano autenticado |
| **Descripción** | El sistema calcula el costo real del viaje sumando transporte, hospedaje y alimentación, comparándolo con el presupuesto diario |
| **Precondición** | Debe existir al menos un presupuesto registrado |
| **Flujo principal** | 1. Selecciona "Planificador de Viaje"<br>2. El sistema calcula: costo promedio de transporte + hospedaje + 3 comidas<br>3. Muestra comparativa: presupuesto diario vs gasto diario estimado<br>4. Muestra desglose por categoría |
| **Flujo alternativo** | 2a. No hay datos suficientes → muestra 0 en categorías sin datos |
| **Postcondición** | Resumen del plan de viaje visible |

### CU-15: Ver reportes y estadísticas
| Campo | Detalle |
|-------|---------|
| **ID** | CU-15 |
| **Nombre** | Reportes y estadísticas |
| **Actor** | Ciudadano autenticado |
| **Descripción** | El ciudadano visualiza estadísticas en 4 pestañas: Resumen General, Presupuestos, Actividades, Ahorro |
| **Precondición** | Sesión iniciada |
| **Flujo principal** | 1. Selecciona "Reportes y Estadísticas"<br>2. Resumen General: cards con totales (presupuestos, restaurantes, destinos, etc.)<br>3. Presupuestos: gráfico de barras con gasto diario por presupuesto<br>4. Actividades: gráfico de barras con actividades por tipo<br>5. Ahorro: gráfico de barras con progreso de metas<br>6. Todos los gráficos se dibujan en tk.Canvas |
| **Flujo alternativo** | 2a. Sin datos → muestra 0 en cards y gráficos vacíos |
| **Postcondición** | Reportes visibles en pantalla |
