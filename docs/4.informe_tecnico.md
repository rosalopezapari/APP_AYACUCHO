## 🎯 2. OBJETIVOS DEL SISTEMA

### 2.1. Objetivo General
Desarrollar una aplicación en Python que permita a **turistas nacionales e internacionales** y locales de la región Ayacucho planificar sus viajes, calcular presupuestos, gestionar destinos turísticos y administrar ahorros para viajes, con recomendaciones **personalizadas** basadas en **preferencias, intereses y presupuesto**.

### 2.2. Objetivos Específicos
1. ✅ Gestionar el registro de ciudadanos
2. ✅ Implementar inicio de sesión con validación de credenciales
3. ✅ Recomendar **destinos turísticos** de la región Ayacucho según presupuesto
4. ✅ Gestionar **restaurantes, hospedajes, transportes y tiendas**
5. ✅ Calcular **presupuestos de viaje** personalizados con desglose
6. ✅ Generar **itinerarios** según días de estadía y preferencias
7. ✅ Implementar **sistema de ahorro** para viajes
8. ✅ Generar **reportes** estadísticos
9. ✅ Recomendar destinos según **presupuesto y provincia**
10. ✅ Soporte **multi-idioma** (español, inglés, francés, portugués)

```python
    preferencias = obtener_preferencias(usuario_id)
    
    # 2. Filtrar destinos según intereses
    for interes in preferencias.intereses:
        destinos = filtrar_por_interes(interes)
        destinos = filtrar_por_precio(destinos, presupuesto_min, presupuesto_max)
    
    # 3. Recomendar restaurantes
    restaurantes = recomendar_restaurantes(presupuesto_min, presupuesto_max)
    
    # 4. Recomendar hospedajes
    hospedajes = recomendar_hospedajes(tipo_viaje, presupuesto_min, presupuesto_max)
    
    # 5. Recomendar transportes
    transportes = recomendar_transportes(presupuesto_min, presupuesto_max)
    
    # 6. Generar itinerario diario
    itinerario = generar_itinerario(destinos, dias_estadia)
    
    # 7. Calcular presupuesto total
    presupuesto_total = calcular_presupuesto_total(recomendacion)
    
    return recomendacion_completa
```
