# BASE DE DATOS - QORY AYACUCHO

**Motor:** SQLite 3  
**Archivo:** `qory_ayacucho.db` (generado automáticamente en la raíz del proyecto)  
**Configuración:** `PRAGMA foreign_keys = ON`, `row_factory = sqlite3.Row`

---

## 1. ESQUEMA RELACIONAL

```
ciudadano 1---* presupuesto
ciudadano 1---* historial
ciudadano 1---* ahorro
```

Las tablas `destino`, `restaurante`, `tienda`, `transporte`, `hospedaje` son independientes (catálogos).

## 4. CONSULTAS CLAVE

```sql
-- Gasto diario del presupuesto
SELECT total / dias AS gasto_diario FROM presupuesto WHERE id_presupuesto = ?;

-- Recomendaciones dentro del presupuesto
SELECT * FROM destino WHERE precio <= ?;
SELECT * FROM restaurante WHERE precio_min <= ?;
SELECT * FROM hospedaje WHERE precio_min <= ?;

-- Planificador integrado
SELECT AVG(precio_min) FROM restaurante;
SELECT AVG(precio_min) FROM hospedaje;
SELECT AVG(precio) FROM transporte;

-- Ahorro: progreso de metas
SELECT meta, monto_actual, monto_objetivo,
       ROUND((monto_actual * 100.0 / monto_objetivo), 1) AS porcentaje
FROM ahorro WHERE id_ciudadano = ?;

-- Destinos por provincia/categoría
SELECT * FROM destino WHERE provincia = ?;
SELECT * FROM destino WHERE categoria = ?;
```
